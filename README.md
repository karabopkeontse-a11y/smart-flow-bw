# Smart Flow BW

Smart Flow BW helps Botswana households detect hidden water leaks, monitor water use, and reduce bills.

## Website
Open `index.html` in a browser or deploy it to GitHub Pages.

## Android app
The native Android source is in `android`. Every push to `main` runs **Build Android APK**. Download the `Smart-Flow-BW-Android-App` artifact from the completed workflow to install the debug APK.

For a Play Store release, sign a release App Bundle with a private signing key.
